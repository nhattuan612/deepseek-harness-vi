# Tài liệu DeepSeek Harness — Tiếng Việt

Tài liệu người dùng tiếng Việt cho DeepSeek Harness và gói ngôn ngữ này. Các hướng dẫn được chia theo chủ đề; mã lệnh và tên tuỳ chọn giữ nguyên để có thể sao chép vào Terminal.

## Hướng dẫn

- [Bắt đầu](user/guide/index.vi.md)
- [Phát triển plugin](user/develop/basic/index.vi.md)
- [Dùng CLI](cli.md)

## Bản dịch giao diện

Cài gói này vào profile `web`, khởi chạy lại DSH rồi chọn **Settings → General → Language → Tiếng Việt**. Các chuỗi giao diện do locale của Harness quản lý được dịch bằng language-pack API chính thức.

## Phạm vi CLI

CLI upstream hiện chưa có API locale. Hướng dẫn CLI được dịch sang tiếng Việt, nhưng `dsh --help`, thông báo lỗi và đầu ra do binary tạo vẫn theo ngôn ngữ của upstream.
